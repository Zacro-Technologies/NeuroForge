This implements a bounded UX-025/INT-006 historical-review follow-up. Sources parse and whitespace checks pass. Five new tests are authored after the successful784-test Mac baseline and await the next integrated build.

Logic history now renders the exact saved input schema's initialState, separately from the representation's variable/type metadata. Saved transitions keep their original order and conditions/mutations; saved invariants keep their text. No current generator or expected final state substitutes for the original starting state. Context and representations respect the snapshot's independent-given roles.

Hints used come from the retained feedback hintLadder prefix bounded by the immutable attempt.hintCount. A missing snapshot or a count exceeding the retained ladder shows an explicit unavailable-text notice. Zero recorded hints never reveals later ladder steps. This is an original support record, not inferred support from current content.

Each saved citation now opens a local read route. AppStore first requires the actual committed attempt, applies protected receipt/snapshot/marker restriction, then resolves the citation ID exclusively inside that attempt's retained exercise. It passes immutable values for the matching source document and chunk; no source model crosses an actor boundary. The resolver checks document/chunk identity, unique matching records, current document/chunk extraction-format version agreement, and recomputes the exact shipped FNV1a64 source-text digest against both the snapshot citation and chunk metadata. Missing/unknown digests, missing chunks and changed source text produce specific recovery text instead of an empty view or a substituted excerpt.

Only source.review.exact snapshots can recover an original excerpt from their self-check referenceAnswer, and only when its digest and declared citation/document/chunk identities match. Generic authored model/reference answers are never relabeled as source excerpts. If a current source is missing or changed, the saved original excerpt can be shown when this exact contract proves it; the current replacement is withheld. User-requested source deletion may also remove the private historical snapshot, in which case the route correctly becomes unavailable.

Existing citation contracts did not retain a original document content revision number or a generic full excerpt. The view states that the original source revision number was not saved. A separately labeled Available extraction version is only the source decoder/format version, never a document content revision. Saved digest/identity remain available in a disclosure. No old numeric version is invented, and no new private excerpt fields are added to possibly sync-eligible generation payloads. Additive local-only citation version/excerpt capture remains a separate future improvement for new items.

Protection is checked before constructing citation titles, digests, actual hints or reference excerpts. The route re-evaluates protection and source availability while open. This work changes only history/review surfaces; live source recall still requires its existing explicit reveal and acknowledged lifecycle.
