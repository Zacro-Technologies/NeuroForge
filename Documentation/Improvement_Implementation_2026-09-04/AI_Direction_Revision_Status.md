# AI direction revision — implementation reassessment

The owner revised the product premise on 5 September 2026. AI tutoring, semantic rubric grading, generation, source learning and coaching are core features; local processing serves useful offline availability. This file records the effect on implementation tracking, not new implementation.

**152 of 258 requirement contracts were added or changed.** Those rows are now `specified` against v1.1 pending reassessment. This does not erase existing code or passing tests. Prior v1.0 statuses and evidence remain in [the preserved ledger](Previous_Requirement_Traceability_v1_0.json). Unchanged contracts use the statuses and evidence already recorded in their owner ledgers. Where that owner ledger was newer than the previous inventory, regeneration reconciles the inventory to those existing notes; it does not represent new implementation. Earlier completion percentages do not measure this revised scope.

The [direction record](../AI_Product_Direction_2026-09-05.md) and [v1.1 specification](../Improvement_Spec_2026-09-04/README.md) take precedence over older status notes that prescribe deterministic-only grading, Shortcut-only AI or privacy-led restrictions. No application code, tests, provider configuration or deployment was changed in this revision.
