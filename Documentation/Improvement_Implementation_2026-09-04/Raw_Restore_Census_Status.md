# Raw destination restore census

Source implemented on 5 September 2026 after the 852/0 unit baseline. All four new DataExportRoundTripTests methods passed in the completed 885-test integrated run (883 methods passed overall; two unrelated obsolete review fixtures failed). This closes a concrete deletion/conflict hole, not MIG-007.

Restore and preview fetch every physical row for all thirteen model categories before touching adaptive history, local learning or core data. Validation, conflict counts, keep-existing choices and deletion use that same captured membership. Rows saved after the UI history projection was last refreshed are included. Duplicate record identities, multiple singleton states, duplicate reflection attempt identities and duplicate checkpoint session identities stop the operation before mutation. The originals remain available to the existing recovery diagnostics; this change does not silently choose or erase a duplicate.

Reflection and checkpoint conflicts recognize their domain identity (attempt or session) as well as their record ID. A new peer record ID for the same domain is skipped by Keep existing or replaced explicitly by Replace matching. Incoming duplicate domains are rejected. Reusing an existing record ID for a different domain is also rejected: a crossed pair must not delete two originals for one incoming row. Preview counts each incoming conflict once.

Four regression methods cover hidden duplicate attempt/reflection/checkpoint/profile rows and every conflict policy; fresh saved rows absent from the UI projection; peer record-ID aliases under every policy; and crossed record/domain identity pairs retaining both originals. They also check unchanged local-learning bytes and adaptive history on rejection. These are real in-memory SwiftData/runtime fixtures, not shipped binary stores or cross-process CloudKit tests.

The multi-store restore still uses in-process compensation. An exact typed raw snapshot codec covering all 13 models and 219 columns is now source-integrated, with six additional tests awaiting compilation/execution. It preserves opaque bytes, unknown raw values and duplicate physical row multiplicity. Durable accepted plans, startup recovery gating, shared write exclusion, CloudKit quiescence and per-operation replay remain unimplemented. This source correction must not be described as crash-atomic restore.
